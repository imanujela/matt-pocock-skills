# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Explainers draw knowledge from here, not from parametric guesses. Wisdom comes from the communities listed here.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Rules

- **High-trust only.** Prefer primary sources, recognised experts, peer-reviewed work, and communities with strong moderation. Leave out marketing dressed as education.
- **Annotate every entry.** A bare link is useless in three months. Add one line: what it covers, and when to reach for it.
- **Group by Knowledge / Wisdom.** This mirrors the split in [SKILL.md](./SKILL.md). A resource may sit in only one group.
- **Surface gaps in the open.** When the mission needs an area and no good source exists, add a `## Gaps` section naming what is missing. That list drives the next search.
- **Prune what failed.** Remove a source that turned out wrong, shallow, or off-mission. Five sharp sources beat thirty mediocre ones.
- **Record a community opt-out.** If the user does not want to join communities, note it here so later sessions stop proposing them.

A resources file is done when every entry is annotated, grouped, and high-trust, every mission area without a source is named under Gaps, and any community opt-out is recorded.
