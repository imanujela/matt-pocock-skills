# Triage labels

The skills speak in five canonical triage roles. This file maps those roles to the label strings this repo's issue tracker actually uses.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires a human to implement |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a role (for example "apply the AFK-ready triage label"), use the matching string from the "Label in our tracker" column.

Edit that column to match the vocabulary you actually use.

**Done when:** every canonical role has exactly one tracker string, and a skill applying a role uses that string.
