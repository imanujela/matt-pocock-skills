# Research

Investigate a question against **primary sources** and leave a cited Markdown file.

Spin up a **background agent** so this session keeps working while it reads. If this harness cannot start a background agent, run the same brief here and say that you did.

The brief:

1. Follow every claim to the source that owns it: official docs, source code, specs, first-party interfaces. A secondary write-up is a pointer, not the source.
2. Write the findings to a single Markdown file. Cite each claim's source beside the claim.
3. Save the file where the repo already keeps such notes. Match the existing convention. If there is none, pick a sensible path and say where.

**Done when:** the file exists, every claim in it cites the source that owns it, the path has been told to the user, and this session either kept working beside a background agent or stated that the brief ran here.
