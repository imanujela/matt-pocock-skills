# Grill with Docs

This session sharpens a plan and leaves a paper trail. The interview and the domain model are two skills. Call both.

Call the Skill tool twice, for "grilling" and "domain-modeling".

Grilling runs the interview. Domain-modeling writes `GLOSSARY.md` and ADRs as terms and decisions resolve. Reading `GLOSSARY.md` for vocabulary is not this skill. That is a one-line habit. This skill is the pair of calls.

**Done when:** both skills have been called, the interview is running through grilling, and any term or decision resolved in this session has been written through domain-modeling (or no term has resolved yet, and the session is still in the interview).
